# Error Handling and I18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a stable backend error contract and frontend i18n-aware error translation layer.

**Architecture:** Backend errors are normalized by `GlobalExceptionHandler` into `ApiResponse` with stable `errorCode` and `traceId`. Frontend API modules throw `AppError`, and UI code translates the error with current locale.

**Tech Stack:** Spring Boot 3, Java records/enums, Vue 3, TypeScript, vue-i18n, Vitest, JUnit.
