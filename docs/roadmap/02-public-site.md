# 02 Public Site 阶段

最后更新：2026-07-04

## 阶段目标

让访客访问项目时看到一个简洁、克制、带轻技术气质的个人主页。公开区域只展示适合访客阅读的内容，工作台入口和能力展示受站点配置与权限控制。

## 已完成

- [x] 创建公开首页 `/`。
- [x] 首页支持站点配置接口 `GET /api/public/site`。
- [x] 首页加载配置前使用骨架屏，避免默认内容闪烁。
- [x] 首页去掉多余 Logo、GitHub 入口、重复中部/底部导航。
- [x] 首页保留顶部导航、个人介绍、终端。
- [x] 首页支持中文、英文、泰文全局语言切换，默认英文。
- [x] 首页支持滚动进度动画：终端下坠淡出，个人介绍居中放大并显示更多内容。
- [x] 个人介绍内容已整理为陈希萌的技术与教学方向。
- [x] 终端命令按登录状态和权限判断可执行性。
- [x] 站点配置可控制个人简介、博客、项目、工作台入口是否公开显示。
- [x] 首页桌面和移动端基本适配。
