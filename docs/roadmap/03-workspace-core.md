# 03 Workspace Core 阶段

最后更新：2026-07-04

## 阶段目标

完成登录后的基础工作台：认证、权限、课程、班级、学期、模板、文件、生成记录、站点配置和权限管理。该阶段是后续文档生成和 AI 接入的业务底座。
